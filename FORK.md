## Why this fork exists

The Lling0000 fork keeps a reusable AI-agent workspace template available for study, local adaptation, and product-facing documentation. It is especially useful as a compact reference for Google Antigravity / Cursor-style rules, MCP setup, agent memory, skills, tools, sandbox execution, and multi-agent routing.

This fork should be read as a forked edition, not as a claim that Lling0000 created the upstream project.
